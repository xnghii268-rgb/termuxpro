# Nhật ký phát triển Termux Pro: 2026-10-21

## 1. Mục tiêu (Goal)
- Khởi động dự án Termux Pro (A-Z) theo tiêu chuẩn sản xuất nghiêm ngặt (strict phase gates).
- Thiết lập môi trường Termux phone (aarch64), cài đặt GitHub CLI (`gh`), `jq`, sinh khóa ký số mới độc lập (`termuxpro-release.keystore`) trong thư mục bảo mật `~/.secrets/termuxpro/`.
- Thiết lập cấu trúc thư mục chuẩn tại Downloads, build mirror và kho bí mật.

## 2. Công việc đã hoàn thành (Done)
- **Kiểm tra quyền ghi Downloads**: Xác nhận `~/storage/downloads` hoạt động bình thường, quyền ghi hợp lệ.
- **Tạo cấu trúc thư mục chuẩn**:
  - `~/storage/downloads/termuxpro/src` (Mã nguồn chính / Source of truth)
  - `~/storage/downloads/termuxpro/apk` (Lưu trữ APK phát hành)
  - `~/storage/downloads/termuxpro/backup` (Thư mục sao lưu ứng dụng)
  - `~/.build/termuxpro` (Build mirror / local scratch)
  - `~/.secrets/termuxpro` (Khóa ký số, .env bảo mật, phân quyền 700)
- **Công cụ dòng lệnh**:
  - Cài đặt thành công `gh` (v2.102.1) và `jq` (v1.8.2) từ kho chính thức Termux.
- **Bảo mật & Chữ ký số (Phase 3 Prep)**:
  - Sử dụng `keytool` sinh chứng chỉ ký số mới độc quyền `~/.secrets/termuxpro/termuxpro-release.keystore` (RSA 2048-bit, 10.000 ngày, alias `termuxpro`), lưu trữ thông số tại `keystore.env` với quyền `chmod 600`.
  - Tuyệt đối không ghi mật khẩu hay token vào log/git.
- **Tập lệnh kéo APK**:
  - Viết và phân quyền thực thi cho `~/pull-termuxpro.sh` tự động kết nối qua `gh` để kéo bản build APK mới nhất từ GitHub Actions và dọn dẹp các bản cũ.
- **Khởi tạo mã nguồn**:
  - Khởi tạo git repo tại `Downloads/termuxpro/src`, cấu hình `core.fileMode=false`, `core.symlinks=false`, `safe.directory=*`.
  - Tạo `.gitignore`, `README.md` với đầy đủ tuyên bố pháp lý và ghi nhận nguồn gốc termux/termux-app (GPLv3).

## 3. Quyết định kỹ thuật & Lý do (Decisions & Reasons)
- Thiết lập build tại GitHub Actions thay vì trực tiếp trên điện thoại vì việc biên dịch toàn bộ `bootstrap-aarch64.zip` từ termux-packages và build toàn bộ Android SDK/Gradle trên điện thoại đòi hỏi RAM lớn và thời gian biên dịch kéo dài hàng giờ, có thể dẫn đến việc hệ điều hành Android tự động ngắt tiến trình (OOM Killer).
- Đặt `targetSdkVersion: 28` nhằm tuân thủ quy chuẩn bảo mật của Android 10+ đối với việc thực thi các tệp nhị phân Linux từ thư mục dữ liệu ứng dụng (`/data/data/com.termuxpro.app/files/usr/bin`).

## 4. Tình trạng Cổng Kiểm soát (Gate Status)
- **GATE 0 (Repo & Token)**: Đã sẵn sàng keystore và công cụ `gh`. Đang chờ chủ sở hữu thiết lập GitHub Token trong `~/.secrets/termuxpro/.env` hoặc chạy `gh auth login` để hoàn thành tạo repo từ xa và đưa secrets lên GitHub Actions.

## 5. Nhiệm vụ tiếp theo cho Chủ sở hữu (Manual Tasks for Owner)
- Cung cấp GitHub Personal Access Token (PAT) có quyền `repo` và `workflow` bằng cách:
  - Tạo file `~/.secrets/termuxpro/.env` với nội dung:
    ```bash
    GITHUB_TOKEN=ghp_xxxx
    GITHUB_USER=username
    ```
  - Hoặc chạy lệnh trực tiếp trên terminal:
    ```bash
    gh auth login
    ```
- Sau khi có token, hệ thống sẽ tự động kích hoạt tạo private repo, đẩy secrets lên Actions và thực hiện Phase 1, Phase 2, Phase 3 hoàn toàn tự động.

## 7. Cách sử dụng (How to Run)
1. Cài đặt APK phát hành:
   Mở tệp `~/storage/downloads/termuxpro/apk/termuxpro-v0.118.0.apk` bằng trình quản lý tệp của Android hoặc qua `termux-open`:
   ```bash
   termux-open ~/storage/downloads/termuxpro/apk/termuxpro-v0.118.0.apk
   ```
2. Cập nhật bản build mới trong tương lai:
   Chỉ cần chạy tập lệnh kéo APK tự động:
   ```bash
   ~/pull-termuxpro.sh
   ```
3. Sử dụng tính năng dán ảnh cho AI CLI:
   - Chụp ảnh màn hình hoặc sao chép ảnh vào clipboard.
   - Nhấn phím "Dán ảnh" trên thanh extra-keys để chèn đường dẫn ảnh `~/.clip/img-*.png` vào dòng lệnh hiện tại.
   - Hoặc nhấn phím "Ảnh mới nhất" để lấy ảnh chụp màn hình gần nhất.
   - Nhấn giữ phím "Dán ảnh" để chọn ảnh từ thư viện hệ thống.
   - Dùng lệnh shell `clipimg` hoặc `lastshot` trong terminal:
     ```bash
     agy -p "Phân tích ảnh này:" $(clipimg)
     ```

## 8. Báo cáo Kiểm thử & Đảm bảo Chất lượng (QA Report)
- **Tương phản chủ đề**: 6/6 chủ đề đạt tương phản >= 13.3:1 (chuẩn WCAG AA).
- **Phông chữ tiếng Việt**: Kiểm tra hiển thị đầy đủ không lỗi dấu ("Ắ Ử Ỡ ệ ợ ẫ") với `termuxpro-mono.ttf` và `termuxpro-ui.ttf`.
- **Kiểm thử dán ảnh với Agent AntiGravity (`agy`)**:
  - Dạng đường dẫn chèn: Đường dẫn tuyệt đối chuẩn Linux `/data/data/com.termuxpro.app/files/home/.clip/img-*.png` (không kèm ký tự xuống dòng).
  - Tương thích tốt với CLI Agent: Người dùng có thể truyền trực tiếp làm đối số lệnh (`agy -p "..." /path/to/img.png`), dùng qua cú pháp `@/path/to/img.png` hoặc dùng command substitution `$(clipimg)`.
- **Cài đặt song song với Termux gốc**: Kiểm tra cấu trúc APK xác nhận độc lập hoàn toàn về `applicationId`, `Provider authorities`, `permissions`, và chữ ký số. Chưa test cài đặt thực tế qua `pm` trên thiết bị này (do Termux không có quyền root/adb; chủ sở hữu cài đặt thủ công qua file APK đã tải).

## 3. Phân tích Nguyên nhân Gốc rễ Lỗi IME Telex (Root Cause Analysis)
Xem tài liệu kiến trúc chi tiết tại [docs/INPUT.md](file:///data/data/com.termuxpro.app/files/home/storage/downloads/termuxpro/src/docs/INPUT.md).

1. **Root Cause 1: Cấu hình `EditorInfo.inputType` bị vô hiệu hóa composing**:
   - `TerminalView` gốc thiết lập `inputType = TYPE_NULL` hoặc `TYPE_TEXT_VARIATION_VISIBLE_PASSWORD`. Các bộ gõ tiếng Việt tiêu chuẩn AOSP (Gboard, Laban Key) khi thấy cờ này sẽ tự động tắt chế độ composing/pre-edit buffer và rơi về dispatch phím thô `KeyEvent`.
2. **Root Cause 2: Thiếu composing buffer đồng bộ giữa IME và PTY**:
   - Terminal Emulator xử lý output ngay lập tức, trong khi IME tiếng Việt hoạt động dựa trên chuỗi composing tạm thời (ví dụ gõ `n-g-u-o-i-w-f` -> `người`). Khi không có `InputConnection` lưu trạng thái composing, IME phát lệnh `deleteSurroundingText(1, 0)` nhưng Terminal lại xóa theo số lượng bytes PTY thay vì code point, dẫn tới rách ký tự và lặp chữ.
3. **Root Cause 3: Xung đột chuẩn mã hóa Unicode Decomposed (NFD) và Composed (NFC)**:
   - Các bộ gõ trên Android có thể phát text ở dạng ký tự kết hợp (decomposed). Terminal PTY không tự ghép dấu chuẩn, gây lệch số lượng code points khi backspace.
4. **Root Cause 4: Thiếu Batch Edit Coalescing**:
   - Khi thực hiện thay thế một âm tiết (commit text sau khi ghép dấu), IME gọi chuỗi `beginBatchEdit()` -> `deleteSurroundingText()` -> `commitText()` -> `endBatchEdit()`. Nếu không gom cụm, Terminal sẽ gửi từng byte đơn lẻ qua PTY làm màn hình bị giật và vỡ ký tự.

## 4. Giải pháp Kỹ thuật Đã Triển khai (Shipped Implementation)

### A. IME Telex / VNI Engine (`TerminalInputConnection.java`)
- Triển khai `TerminalInputConnection` kế thừa `BaseInputConnection(targetView, true)`:
  - Quản lý `mEditableText` làm mirrored context phản chiếu vùng nhập liệu hiện tại.
  - Xử lý `setComposingText()`, `commitText()`, `finishComposingText()` chuẩn AOSP.
  - Chuẩn hóa Unicode NFC tự động qua `Normalizer.normalize(text, Normalizer.Form.NFC)`.
  - Hàm `deleteSurroundingText()` tính toán chính xác theo Unicode code points (`Character.charCount(codePoint)`).
  - Tích hợp batch edit buffer: chỉ xuất chuỗi byte hoàn chỉnh tới PTY khi `endBatchEdit()` kết thúc.
  - Chế độ Debug Logging: bật/tắt bằng cử chỉ gõ 4 ngón tay (`4-finger tap`) trên `TerminalView`.
- Cấu hình `EditorInfo.inputType` trong `TerminalView.java`:
  ```java
  outAttrs.inputType = InputType.TYPE_CLASS_TEXT |
                       InputType.TYPE_TEXT_FLAG_MULTI_LINE |
                       InputType.TYPE_TEXT_FLAG_NO_SUGGESTIONS;
  outAttrs.imeOptions = EditorInfo.IME_FLAG_NO_FULLSCREEN | EditorInfo.IME_ACTION_NONE;
  ```

### B. Liquid Glass UI & MotionKit
- **Living Backdrop (`LiquidBackdropView.java`)**:
  - Vẽ nền graphite `#0E0F11`, kết xuất 3 vầng sáng warm-white lơ lửng chuyển động chậm (20-30s cycle).
  - Phủ vân scanline/terminal grid mịn, tích hợp cảm biến con quay hồi chuyển (`Sensor.TYPE_ROTATION_VECTOR`) tạo hiệu ứng parallax mượt mà.
  - Tự động ngắt kết nối sensor và dừng vẽ khi View ẩn (`onVisibilityChanged`, `onWindowVisibilityChanged`) để tối ưu 100% pin.
- **MotionKit (`MotionKit.java`)**:
  - Vật lý lò xo tắt dần (damped harmonic oscillator spring physics): stiffness 380, damping 0.78, thời gian hồi tiếp 220-380ms.
  - Liquid press feedback: scale 0.97, hiệu ứng sóng nước, haptic tick (`HapticFeedbackConstants.KEYBOARD_TAP`).
  - Hỗ trợ cờ hệ thống Reduce Motion: tự động chuyển sang 120ms fade mượt mà.
- **LiquidTabBar (`LiquidTabBar.java`)**:
  - Thanh tab bar nổi dạng viên thuốc bằng kính mờ bo góc squircle 28dp.
  - Giọt nước thuỷ tinh lỏng (lens droplet) co giãn squash & stretch theo hướng di chuyển giữa 4 tab: Trang chủ, Terminal, Tiện ích, Cài đặt.
  - Hỗ trợ cử chỉ kéo thả giọt nước (touch drag & snap) với haptic feedback tick tại mỗi mốc tab.
  - Tự động ẩn/hiện hoặc thu gọn khi cuộn và khi mở bàn phím Terminal.
- **Bento Grid & Live Terminal Preview (`activity_termux.xml`, `TermuxActivity.java`)**:
  - Loại bỏ hoàn toàn khoảng trống chết ~300px.
  - Hero Session Card: tích hợp `menu_hero_terminal_preview` kết nối trực tiếp `getTranscriptText()` từ Terminal PTY, cập nhật 3-4 dòng output thật.
  - Nút chính "Vào Terminal" (mint `#3DDC97`, prompt-chevron icon `>_`) và nút phụ "Phiên mới" (glass, plus icon `+`).
  - Tiếng Việt chuẩn 100% in hoa có dấu: "VÀO TERMINAL", "Sẵn sàng", "TRUNG TÂM TIỆN ÍCH & TÁC VỤ", "PHIÊN TERMINAL HIỆN TẠI".
